# Project-based roadmap

## Phase 1: Python through a Workshop tool

Build a CLI, validation, models, JSON persistence, tests, FastAPI, PostgreSQL, and async I/O.

## Phase 2: StitchPad structured extraction

Convert typed and photographed notes into validated drafts. Add manual correction, confirmation, and at least 50 evaluation cases.

## Phase 3: Retrieval and RAG

Build semantic search first, then a focused AgricTech assistant with citations, refusal behavior, and 75-100 evaluation questions.

## Phase 4: Tools, workflows, and MCP

Build raw tool calls, deterministic workflow state, retries, approval boundaries, then one small MCP server.

## Phase 5: Production AI

Add Docker, CI, deployment, observability, versions, security, load tests, latency/cost budgets, fallback, and rollback.

## Phase 6: Mobile AI and hiring

Integrate the strongest workflow into Android/KMP and benchmark a justified on-device component with LiteRT.
